# 《人工智能通识》配套课程资源建设规划（蓝图）

> 配套通用版教材（13 章），建设三类数字化课程资源，支撑线上线下混合式教学、岗课赛证融通。
> **总量**：知识卡片 50 张 ＋ 微课 40 个 ＋ H5 交互课件 20 个 ＝ **110 项**。
> **设计原则**：颗粒化（一卡/一课/一件聚焦一个知识点）、可操作（紧扣教材实训）、国产工具为主、统一视觉（科技蓝 #2E6BE6＋活力橙 #FF8A3D）。

## 四、统一规范

- **视觉**：科技蓝 #2E6BE6 ＋ 活力橙 #FF8A3D ＋ 辅助灰；圆角卡片、扁平图标、微软雅黑。
- **工具**：一律以国产工具示范（DeepSeek、文心一言、通义、扣子等）。
- **对应**：每项资源标注"对应教材第 X 章 X.Y 节"，与实训任务联动。
- **交付**：知识卡片（md＋HTML 翻转卡）、微课（脚本 md，供录课）、H5（可运行 HTML 源码＋说明）。
