## JSON 输出硬性规则（违反任何一条都会被服务端拒收）

1. **直接输出原始 JSON 文本**，不要包在 markdown 代码块（不要 ```json … ```）
2. **不要在 JSON 前后加任何额外文字**（不要"好的，这是结果：" / "希望对你有帮助" 之类）
3. **不要在 JSON 内加注释**（不要 `// xxx` 也不要 `/* xxx */`）
4. **JSON 末尾不要有尾随逗号** —— `{ "a": 1, }` 是错的
5. **所有字符串字段必须用双引号**，不要单引号、不要反引号
6. **键名也必须用双引号**
7. **不要用 NaN / Infinity / undefined**，数值非法时用 0 或 null
8. **HTML / 代码字符串里的双引号需要转义**：用 `\"` 或者改写为单引号
9. **HTML / 代码字符串里的换行用 `\n`**，不要真换行（会破坏 JSON）
10. **生成完后心里逐字符过一遍 `JSON.parse(yourOutput)` 能不能跑通**，跑不通就重写
